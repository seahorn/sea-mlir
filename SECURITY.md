# Security reports

Report suspected security vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/seahorn/sea-mlir/security/advisories/new).
Include the affected revision, a minimal reproducer, the command you ran,
and the expected and observed behavior. Remove credentials and private data.
Please keep vulnerability details out of public issues until the maintainers
have coordinated disclosure.

For ordinary bugs and questions, use
[GitHub issues](https://github.com/seahorn/sea-mlir/issues).
